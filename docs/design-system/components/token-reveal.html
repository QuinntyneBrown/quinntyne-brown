Token reveal

A new agent token, shown once with a copy button.

WCAG 2.2 AAStatus: new

Overview

The token reveal shows a new agent token exactly once, right after it is issued, with a Copy button. When the dialog closes, only the prefix remains anywhere in the app.

Copy this token now. You won’t see it again.

Use it as Authorization: Bearer ftca_…. It works for Shelfie until Thu 20 Nov.

Anatomy

  1. PanelWarning tint with a warning icon and the title “Copy this token now. You won’t see it again.”
  2. Copy fieldThe full ftca_… token, read-only, with Copy token (see Copy field).
  3. Usage hintHow to send it and where it works until when.

Variants

One variant; the hidden state is what remains after closing.

Sizes

One size; fills the dialog body.

Copied changes the button to “Copied” and announces “Token copied to the clipboard.” Hidden is how a token appears afterwards: its prefix only.

Responsive behaviour

The token truncates with an ellipsis in the field at narrow widths and stays fully selectable.

Theming

Text --color-fg-default on --color-warning-bg (15.56:1 light, 13.70:1 dark); the field keeps its surface.

Accessibility

  • Focus moves to Copy token when the dialog opens; the title is read first because it is the panel’s first text.
  • The read-only field (not disabled) can be selected by keyboard.
  • The dialog’s only action is “I’ve copied it”; Escape asks nothing more, so people should copy first — the title says so.

Content

  • Title: “Copy this token now. You won’t see it again.”
  • Hint: “Use it as Authorization: Bearer ftca_…. It works for {orgs} until {date}.”
  • Hidden: “{prefix}… You can’t see it again. If it’s lost, revoke it and issue a new one.”
