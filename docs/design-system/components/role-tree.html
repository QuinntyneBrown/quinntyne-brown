Role tree

A catalogue’s roles in order, with display-only nesting and keyboard reordering.

WCAG 2.2 AAStatus: new

Overview

The role tree lists an Org Type’s catalogue roles in order, under the built-in Org Lead and Member. Selecting a role opens it in the editor beside the tree. Indent shows the parent chosen for display only: a role never inherits its parent’s permissions. Move up and Move down reorder with the keyboard.

Anatomy

  1. Built-in tiersOrg Lead and Member, not editable here; Member shows its bundle.
  2. Role rowA button with the name, key (mono) and holders.
  3. Indent--role-depth × --space-6, with an edge on child rows.
  4. Move buttonsIcon buttons named “Move {role} up/down”; disabled at the ends.

Variants

One variant. A type with no roles shows an empty state in the tree’s card instead.

Sizes

One size: 44px rows.

Rows show hover with data-state="hover" and focus rings; the selected row has aria-current="true". Just moved rings the row for a moment and the live region says “Moved Volunteer to position 4 of 7, under Communications Lead.”

Responsive behaviour

Below 1024px the tree sits above the editor; indents shrink to fit by wrapping the meta line. Move buttons stay visible on touch.

Theming

Selected rows use --color-accent-subtle and an accent edge; child edges use --color-border-default.

Accessibility

  • An ordered list named “{Type} roles, in order”; each row is a button (selecting) plus two move buttons, so no drag is needed (WCAG 2.5.7).
  • Focus stays on the move button after a move, and a polite live region announces the new position.
  • The current role is aria-current="true".

Content

  • Meta: “{key} · {n} people”.
  • Under the tree: “Indent shows the parent for display only. A role never inherits its parent’s permissions.”

Code

<ft-role-tree
  label="FaithTech City roles, in order"
  [roles]="roles"            // { id, key, name, depth, holders }[]
  [selectedId]="selected"
  [announcement]="moveMessage()"
  (select)="open($event)"
  (move)="reorder($event)"     // { id, direction: 'up' | 'down' } />
Input / outputType and defaultMeaning
rolesRoleTreeItem[], []In display order; depth is the indent.
selectedIdstring | nullMarks the current role.
memberBundlestring, ''Caption for the built-in Member.
announcementstring, ''Polite live text after a move.
selectoutput<string>Role id chosen.
moveoutput<{ id, direction }>Reorder request.
