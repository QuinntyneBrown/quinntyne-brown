Org switcher

The active organization in the top bar, and the menu to switch between every org a person covers or to All orgs.

WCAG 2.2 AAStatus: new

Overview

The org switcher sits in the top bar after the portfolio mark. It shows the active organization’s mark and name and opens a menu of every org the person covers, each with its Org Type, plus All orgs. Choosing an org keeps the current section when that org has the feature, otherwise opens its home. People who cover one org get no switcher: the bar shows that org’s mark and name as plain text.

Anatomy

  1. ButtonA menu button (aria-haspopup="menu"): org mark, name (from 1024px) and chevron.
  2. Org markThe org’s logo, or its initials on --color-org-accent with --color-org-accent-foreground. See Org label and mark.
  3. Menu headerThe portfolio name and how many orgs the person covers.
  4. Org optionsmenuitemradio rows: mark, name (truncated), Org Type caption and a check on the active one.
  5. All orgsAfter a divider: the read and assigned-work view across every covered org.

Sizes

One size: the button is 44px tall (--target-comfortable) with a 32px mark (--size-avatar-sm); options are 44px tall.

Open sets aria-expanded="true" and tints the button. The active org’s row is tinted and checked (aria-checked="true"). Long name truncates with an ellipsis at --org-switcher-name-max (10rem); the full name stays in the accessible name and the title.

Responsive behaviour

  • Below 1024px the button shows only the mark and chevron; the name stays in its accessible name.
  • The portfolio name beside the brand mark appears only from 1536px; below that the switcher takes its room.
  • The menu opens under the top bar at the page margin, at most 22rem wide or the viewport less its margins, so it never overflows a 360px phone.
  • With the switcher in the bar the primary nav scrolls sideways inside the capsule, as ft-top-bar does.

Theming

The button and menu use surface, border and accent-subtle roles, so they follow the theme. Only the org mark reads --color-org-accent and its foreground, set per option from the org’s branding. Every saved pair passes 4.5:1, so the initials are readable in both themes.

Accessibility

  • WAI-ARIA menu button pattern: button[aria-haspopup="menu"][aria-expanded] controls a role="menu" of menuitemradio links with aria-checked on the active org (CDK Menu in Angular).
  • Keyboard: Enter, Space or ↓ opens with focus on the active org; ↑ ↓ move, Home and End jump, Enter chooses, Escape closes and returns focus to the button, Tab closes.
  • The button’s name starts with the visible org name: “FaithTech Toronto, switch organization” (WCAG 2.5.3 Label in Name). Each option is announced as “Shelfie, Startup, menu item radio, not checked, 2 of 3”.
  • After a switch, focus goes to the new page’s heading and the shell announces “Switched to Shelfie”.
  • Contrast: button text on surface uses --color-fg-default; the org mark pair is refused below 4.5:1 when branding is saved (L2-149).

Content

  • Org names as the org set them; never abbreviate. The caption is the Org Type name.
  • “All orgs” and its caption “Read and assigned work across {n} orgs”.
  • Menu header: the portfolio name, then “Portfolio · you cover {n} orgs”.
