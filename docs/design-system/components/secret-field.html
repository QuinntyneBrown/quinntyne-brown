Secret field

A signing secret shown once with Copy, then masked to its prefix.

WCAG 2.2 AAStatus: new

Overview

The secret field shows an application’s signing secret exactly once, when it is registered or rotated, with a Copy button. As soon as the secret has been copied it is masked to its prefix and cannot be shown again, in the dialog or anywhere else; the application’s page always shows the masked state. It differs from Token reveal in masking itself after the copy rather than when the dialog closes.

Anatomy

  1. PanelWarning tint, warning icon and the title “Copy this secret now. You won’t see it again.”
  2. Copy fieldThe full whsec_… secret, read-only, with Copy secret (see Copy field).
  3. HintWhere to keep it.
  4. Masked panelSunken surface, lock icon, the prefix and how to get a new secret.

Variants

Two: shown (a value is given and not yet copied) and masked (no value, or copied).

Sizes

One size; fills the dialog body or a description list cell.

Copied announces “Secret copied to the clipboard.” and replaces the field with the masked panel, which is a status region so the change is announced. If the clipboard is refused, the value stays shown and selected so it can be copied by hand.

Responsive behaviour

The secret truncates in the field at narrow widths and stays fully selectable; the masked panel wraps.

Theming

Text --color-fg-default on --color-warning-bg (the token reveal pair, 15.56:1 light, 13.70:1 dark); the masked panel uses --color-fg-default on --color-bg-surface-sunken. No new tokens.

Accessibility

  • The title is the panel’s first text, so it is read before the field.
  • The read-only field (not disabled) can be selected by keyboard.
  • After copying, focus stays on the dialog’s primary action; the masked panel is role="status".

Content

  • Title: “Copy this secret now. You won’t see it again.”
  • Masked after copying: “Secret copied and hidden. {prefix}… You can’t see it again. If it’s lost, rotate the secret to get a new one.”
  • Masked on a page: “Hidden. {prefix}… Rotate the secret to get a new one.”
