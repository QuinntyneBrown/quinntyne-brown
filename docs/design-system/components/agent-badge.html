Agent badge

Overview

The Agent badge marks a profile of kind Agent (an AI helper) wherever it appears: People, pickers, activity feeds, the audit log and its profile. It is the agent variant of Badge.

BHBacklog HelperAgent
BHBacklog HelperAgent

Anatomy

  1. IconThe bot icon in --color-info-icon, decorative.
  2. Word“Agent”, sentence case, label weight, extra-small size.

Variants

One variant, alongside the badge’s neutral, status, role and count variants.

Sizes

One size, matching the role badge height (24px minimum target).

States

ThemeDefaultIn a rowWith roles

The badge is not interactive and has no hover or focus state.

Responsive behaviour

Never wraps inside; sits after the name and wraps to the next line with it in narrow cells.

Theming

Text --color-fg-default on --color-info-bg (14.85:1 light, 13.81:1 dark).

Accessibility

  • The word “Agent” is the cue; the icon is decorative.
  • Screen readers read it after the name: “Backlog Helper, Agent”.

Content

Always “Agent”. Do not add the model or vendor.
