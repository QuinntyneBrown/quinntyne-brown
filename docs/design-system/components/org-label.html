Org label and mark

Which organization something belongs to: a text label for combined lists, and the org’s mark.

WCAG 2.2 AAStatus: new

Overview

An org label says which organization a row, result, notice or announcement belongs to, wherever lists combine orgs (All orgs, search, notifications, the portfolio audit log). The org mark is the org’s logo, or its initials on the org accent; it identifies the org in the switcher, the organizations list and branding previews.

Anatomy

  1. Label pillCaption text on --color-bg-subtle, never wraps; long names end in an ellipsis.
  2. Accent dotDecorative 8px dot in the org accent with a hairline ring, so a pale accent still shows. The name, not the colour, identifies the org.
  3. Org markSquare with rounded corners (round inside the switcher), the logo image or the initials on the accent pair.

Org band

The org band (ft-org-band) heads the public event page and the connect page: the org mark on a surface chip and the display name, on the accent pair. It is decorative chrome; the page’s overline and “Hosted by” repeat the org name as text.

Org (default) and Portfolio (for portfolio-wide announcements and items; accent-subtle with the brand accent text). Marks: org initials, logo (an <img> filling the square), and All orgs (the neutral layered icon).

Labels and marks are not interactive. No branding falls back to the default pair (--color-accent with --color-fg-on-accent).

Responsive behaviour

The label never wraps; in narrow table cells it truncates at the cell width with the full name in title. Marks keep their size at every width.

Theming

The label’s text and pill follow the theme (--color-fg-muted on --color-bg-subtle, 5.06:1 light, 6.60:1 dark). The dot and mark read the scoped pair set on the element from the org’s branding, so they look the same in both themes.

Accessibility

  • The label is text: screen readers read the org name. The dot is aria-hidden; colour is never the only cue.
  • Marks are decorative (aria-hidden) next to a visible name; where a mark stands alone, the surrounding control carries the name.
  • Initials on the accent pass 4.5:1 because branding below that is refused (L2-149 AC5).

Content

  • The org’s display name in full; “Portfolio” for portfolio-wide items.
  • Initials: up to two letters from the display name (“FT”, “S”).
