# Agents and tokens

## opening: Opening
In this video the Portfolio Lead creates an agent and gives it a token. The app is real; the server is a local stand-in, and the people are made up.

## create: Create an agent
An agent is a profile that signs in with a token rather than a password. Name it Sprint Bot and it joins the list.

## issue: Issue a token
Give the token a name and choose which organizations it may reach. The token is shown once, with a warning that it will not be shown again, so copy it now.

## listed: Scoped to what you chose
Back on the list, the token appears with the organizations it covers and no way to read it again.

## revoke: Revoke it
Revoking asks first. Confirm, and the token is marked revoked and stops working at once.

## closing: Summary
That is an agent: a profile that holds roles, reached through scoped tokens that are shown once and can be revoked at any time.
