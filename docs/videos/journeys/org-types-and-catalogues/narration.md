# Org Types, features and roles

## opening: Opening
In this video the Portfolio Lead shapes an Org Type: which features it has and which roles people can hold. The app is real; the server is a local stand-in, and the people are made up.

## types: The Org Types
Each organization has a type. The list shows how many roles each type offers; FaithTech City has seven.

## features: Turn a feature off
Open Startup and its Features tab. Profiles is built in and cannot be turned off. Switch Resources off for every startup and save. Those organizations no longer see Resources.

## catalogue: The role catalogue
Back in FaithTech City, the catalogue lists its roles and how many people hold each. One person is a Volunteer.

## add-role: Add a role
Add a role by naming it, giving it a key and ticking what it may do. This Mentor can see the People page, and it appears in the catalogue straight away.

## held-role: A held role stays
Try to remove Volunteer and the app refuses, naming Ruth Alvarez, who holds it. Reassign her first, then remove the role.

## closing: Summary
That is an Org Type: features switched on per type, roles built from permissions, and a guard that keeps a role in place while anyone holds it.
